# 双语术语示例

以下是命名方式的少量示例，用于讨论中文表达及其与英文教程的对应关系。

| 中文表达 | 英文名称 |
| --- | --- |
| 噪声 | Noise |
| 单纯形噪声 | Simplex Noise |
| 融合球（元球） | Metaballs |
| 扭曲（旋扭） | Twist |
| 波纹 | Ripple |
| 曲线 | Curves |

采用完整英文名称而不是缩写，便于查找官方文档和对照教程。中文名称在准确表达功能的同时，也考虑常见说法与学习时的识别成本。

术语合理性与具体检索效果是两个检查方向：目录中保留了中英文，并不自动证明所有搜索入口都能匹配每一种表达。实际结果会继续记录在验证文档中。
