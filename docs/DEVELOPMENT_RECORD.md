# 开发过程与版本记录

维护与 2.8 适配整理：[ko1btt](https://github.com/ko1btt)。本次开发与文档整理使用了 AI 辅助。

## 需求与改进过程

1. 从旧切换器不能识别本机 2.8 安装的问题入手，调查实际资源布局。
2. 保留原版英文备份，整理已有词库与补充翻译，完成初版界面适配。
3. 根据使用反馈，加入无衬线中文字体与中文、英文并列目录名称。
4. 扩展 2.8 新内容和遗漏内容，并对显示文本修改范围进行检查。
5. 将兼容检查、备份、修复、恢复、字体设置和诊断整理到图形安装器。
6. 根据其他电脑的反馈，改进目录选择、快捷方式解析和自动发现，并增加诊断信息。

## 2026-10-17：v1.0.0
