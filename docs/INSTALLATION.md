## 成品安装包的主要功能

- **中文界面**：整理 17 份语言资源，涉及菜单、属性、节点、滤镜及部分教学文字；与原版不同的显示文本位置共 8,554 处。
- **中英双语目录**：目录名称并列保留中文和完整英文，例如“形态变换 Morph”“网格求解器 Mesh Solver”“曲线 Curves”，便于对照教程。
- **检索与术语对照**：数值类名称补充“数字”词；实际截图已展示中文“网格”“颜色”和英文 `shape` 能返回相应结果。其他词条、同概念中英配对查询和全部入口仍需继续验证。
- **补充译文**：在第一轮适配基础上补充 616 处文本，涵盖 2.8 新内容和先前遗漏内容。
- **中文字体设置**：使用 Noto Sans SC 无衬线字体，缺少该字体时可由安装器离线部署。
- **图形安装与诊断**：提供自动查找、目录或程序选择、路径粘贴、资源检查、本地诊断导出，以及安装、修复和恢复操作。

双语主要用于目录名称；其他界面文字主要为中文。上述统计是文本位置与目录记录数，不代表全部独立功能的数量。菜单截图仍有少数英文条目，全部应用文字和扩展内容的翻译覆盖尚未完成核对。

安装器本身可离线运行，使用时无需 Python 或原来的 Cavalry Language Switcher。获取安装包的下载过程仍需网络。

## 下载与安装

1. 从官方渠道安装目标 Cavalry，先确认它本身能正常启动。
2. 通过闲鱼商品页核对兼容要求、交付内容与支持范围，购买后按订单说明获取安装包。
3. 将整个 ZIP 完整解压到本地独立文件夹，保留说明、许可及随附文件。安装器无需放入 Cavalry 安装目录。
4. 保存项目并完全退出 Cavalry，再运行 `Cavalry-双语安装器.exe`。
5. 使用“自动查找”，或通过“选择文件夹”选择安装目录并点击“确定”；也可使用“选择程序”选择真正的 `Cavalry.exe` 或桌面快捷方式。输入框支持直接粘贴路径。
6. 检查结果显示匹配后，点击“安装 / 修复双语”，按 Windows 提示完成本次操作所需的权限确认。
7. 安装完成后关闭安装器，从平时使用的图标重新打开 Cavalry。
8. 检查中文界面与字体，并在实际搜索栏分别输入“网格”“shape”“颜色”，对照[已有截图](BILINGUAL_SEARCH.md)确认结果。

有多套 Cavalry 时，应核对真正运行的那一套。若需要借助运行中的程序查找路径，可先打开 Cavalry 再自动查找；定位后保存并完全退出，才能开始安装。

## 恢复安装前状态

保存项目并退出 Cavalry，重新运行安装器，选择同一个安装目录，点击“恢复安装前状态”。

安装目录下的 `.cavalry-bilingual/` 保存状态与备份，请保留。修复安装会保护首次原版备份；如果文件已被其他工具修改，恢复检查可能停止，需先核对诊断信息。

恢复主要还原本包涉及的界面文本和字体设置；后续自行调整的主题或字体设置会尽量保留。已部署到 Windows 的 Noto Sans SC 属于共享字体，恢复时会继续保留。

## 常见情况

### 自动查找没有找到位置

可选择文件夹、选择 `Cavalry.exe` / 桌面快捷方式，或直接粘贴路径。自动发现还可参考正在运行的 Cavalry；定位成功后需退出 Cavalry 再安装。

### 软件能打开，但检查提示缺少 theme.json 或其他资源

先核对实际运行位置，再导出诊断。能启动不代表资源布局与本包基线相同；缺失原因仍需逐项核对。请保留原目录结构，不通过补建空目录或移动 DLL 强行通过检查。

### 已经装过其他汉化

先使用此前保留的备份恢复匹配的原版资源，再评估本包。安装器会保护原版备份，不把已被修改的文件当作新的英文原件。

### 更新或重新安装 Cavalry 后，汉化消失或检查不匹配

更新可能覆盖语言资源，也可能改变文件结构。需要重新核对兼容性，不能直接认定旧安装包适用于新的构建。

### 安装器出现系统提示，或安装过程失败

当前安装器未做数字代码签名。本包无需关闭杀毒软件或 Windows 文件夹保护；遇到阻止或写入失败时，保留提示、备份与诊断信息后排查。
