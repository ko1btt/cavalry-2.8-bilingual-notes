# 公开目录词库

本目录分享 Cavalry 2.8 双语适配中的完整目录名称记录，供术语对照、翻译协作和其他项目对接使用。它涵盖基础类型、形状、行为、变形器、滤镜、工具和辅助类型等名称。

## 文件

| 文件 | 数量 | 用途 |
| --- | --- | --- |
| [完整在线对照表](NODE_NAMES.md) | 432 条唯一词条 | 浏览中文、英文和 type 标识 |
| [CSV](node-names.csv) | 432 条唯一词条 | 用 Excel 或其他表格软件打开；UTF-8 BOM 编码 |
| [JSON](node-names.json) | 432 条唯一词条 | 按数组读取，便于开发与翻译协作 |
| [原始目录记录 JSON](node-names-source.json) | 434 条原始记录 | 保留原始顺序、字段与重复记录，方便核对 |

原始表中的“颗粒 Grain”和“高斯模糊 Gaussian Blur”各出现两次，因此 434 是资源记录数；去重后的词条数是 432。它们不是 434 个互不相同的软件功能。

## 字段与示例

- `type`：资源中的类型参考标识。
- `english`：完整英文名称。
- `chinese`：从现有双语名称中提取的中文部分。
- `bilingual_name`：当前采用的完整双语显示名称。

```json
{
  "type": "meshSolver",
  "english": "Mesh Solver",
  "chinese": "网格求解器",
  "bilingual_name": "网格求解器 Mesh Solver"
}
```

例如：形状 Shape、网格布局组 Grid Layout Group、网格形状 Mesh Shape、颜色信息 Color Info、形态变换 Morph、曲线 Curves、二维数值（数字） Value2。

原始表沿用 `type`、`name`、`english` 三个字段；去重表新增拆分后的中文与双语显示字段。词库来自本项目 v1.0.1 的目录名称记录，没有为本次展示重新编造译名。
